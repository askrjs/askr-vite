# Public API review for 0.5.0

Reviewed against accepted source `a50dbb235ff915c9b44c061d6952660ccf0b33f0`. The four public export keys and every existing conditional target remain. The 28 named/type/path pairs become 18: 18 retained, nine removed, and one duplicate type moved to its existing owner. Five runtime values and 13 type pairs remain.

The separately retired `AskrVitePluginOptions.ssrPrecompile` property was never read by the transform implementation and never changed output. See [migration instructions](migration-0.5.0.md).

`createDocumentApp` remains public because the production virtual server module imports it from the installed `/server` entry. Private marker and composition implementations remain available inside this package; package-private paths are not supported imports.

`/image` retains its Node checked-metadata condition and browser/import/default runtime condition. Browser bundles use the transformed image adapter; direct Node SSR/SSG reads metadata from the preceding client build. There is no new CommonJS entry or cancellation API.
